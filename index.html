First-time setup

Follow the steps in order. Tap a step's number to mark it done. Your progress is saved in this browser.

This guide is written by the Yari support team. If these steps don't fix your issue, contact support on Discord.

Disable Fast Startup

Windows
  1. Open Control Panel
  2. Go to Power Options
  3. Click Choose what the power buttons do
  4. Select Change settings that are currently unavailable
  5. Uncheck Turn on fast startup (recommended)
  6. Click Save changes

Disable Secure Boot

BIOS
  1. Restart your computer and enter the BIOS/UEFI settings. The key is usually F2, DEL, ESC or F12 during startup, and varies by system
  2. Find the Secure Boot option
  3. Set Secure Boot to Disabled
  4. Save changes and exit BIOS
  5. Restart your computer

BIOS layouts differ between manufacturers, so the option may sit under a different menu.

Turn off Real-time protection

Windows Defender
  1. Open Windows Security
  2. Go to Virus & threat protection
  3. Click Manage settings
  4. Turn Real-time protection off

You can turn this back on later.

Download the loader and add an exclusion

Windows Defender
  1. Download the loader from the official website
  2. Add the loader to Windows Defender exclusions:
    • Open Windows Security
    • Go to Virus & threat protection
    • Click Manage settings
    • Scroll to Exclusions and click Add or remove exclusions
    • Click Add an exclusion
    • Select File and choose the loader

Once the exclusion is added, you can turn Real-time protection back on if you want.

Only download the loader from the official website. Never add an exclusion for a file from anywhere else.

Run the loader

Two runs

First run

  1. Right-click the loader and choose Run as administrator
  2. Log in to the loader
  3. Click Load
  4. Wait while it processes
  5. When prompted, click Restart

After the restart

  1. Run the loader again as administrator
  2. Click Load
  3. Wait for the process to finish
When you see Successful Injection, the program has loaded and you can start the game.

Stuck in a restart loop or no success message? See Won't inject / keeps asking to restart.

Base fixes

Try these before moving on to the specific fixes below.

Clear temporary files

Maintenance
  1. Press Windows + R, type and delete everything inside
  2. Press Windows + R again, type and delete everything inside

Reinstall the launcher

Environment
  1. Open the Yari Launcher and find its main directory path
  2. Delete the root Yari folder
  3. Download the build installer again

Check security settings

Configuration
  • Fast Boot is disabled, in Windows Power Options or the BIOS
  • Secure Boot is turned off
  • Core Isolation is turned off. How to turn off Memory Integrity
Specific fixes & troubleshooting

Find the problem you're seeing and open it for the solution.

Loader keeps asking for restart / fails to inject

Solution: turn off Memory Integrity

  1. Open Windows Security
  2. Go to Device security
  3. Click Core isolation details
  4. Turn Memory integrity off
  5. Restart your computer
Yari Launcher not opening

Solution: install WebView2

Download Microsoft Edge WebView2 Evergreen Standalone and choose the version that matches your Windows installation (x64, x86 or ARM64). You can check yours under Settings → System → About, next to System type.

GTA not starting automatically after the second injection

This is normal

On some builds the game doesn't launch by itself. Start the game executable manually.

Windows enters Recovery Mode after bootkit use

Solution: disable Secure Boot completely

Follow Step 2 again and make sure Secure Boot is set to Disabled.

If Windows keeps looping back into Recovery Mode, do a clean Windows reinstall using an 8 GB USB drive and the official Windows ISO.

A clean reinstall can erase your files. Back up anything important first.
Bootkit fails to initialize despite a correct setup

Solution: scan and repair system files

  1. Open Command Prompt as administrator
  2. Run
  3. Wait for the scan to finish
  4. Try initializing again
Can't log in with your website credentials

Solution: turn off 2FA for now

Temporarily disable Two-Factor Authentication (2FA) on the official website, then try logging in to the loader again.

Instant Finish doesn't work

Solution: turn off Free Shopping

Instant Finish won't work while Free Shopping is enabled. Disable Free Shopping, then try Instant Finish again.

Overload doesn't show

Solution: make the game window borderless

Overload only shows when the game window is borderless. In GTA V, open the graphics settings and set Screen Type to a borderless option instead of Fullscreen.

Can't claim the Discord role

Solution: check your license and linked account

The role is only available to users with a Yari license. Make sure your license key is activated, then add your Discord account under Profile → Accounts. The full walkthrough is in Claim your Discord role.

Claim your Discord role

Link your Discord account on the Yari website to claim the User role.

You must be a user with a Yari license to claim this role.
  1. Launch your web browser and go to Yari.one
  2. Click Sign In at the top right of your screen
  3. Sign in to your account
    • You need to sign up first if you don't have an account
  4. Activate your license key if you haven't done so already
  5. Go to your profile page
    • It's located next to the Dashboard icon
  6. Click Accounts
  7. Add your Discord account to claim the User role

Having trouble with these steps? See Can't claim the Discord role or contact support.
